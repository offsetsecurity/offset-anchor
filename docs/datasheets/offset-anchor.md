# Offset Anchor

**For NIST SP 800-53 Rev. 5 and the Risk Management Framework.** Choose a
baseline, implement it, and put together the package for an authorisation. On
your own server.

## Who it is for

Teams securing a system against SP 800-53: government bodies and their
suppliers, and any organisation that has adopted the catalogue for a system
that has to be authorised or assessed.

## What you get

| | |
|---|---|
| **The catalogue** | All 1,014 controls and enhancements, in 20 families |
| **System & Baseline** | The system, its boundary, its authorising official and authorisation dates, and the Low, Moderate or High baseline applied in one step (149, 287 or 370 controls) |
| **Tailoring** | Take controls out or bring them in, with the rationale kept on each |
| **Organisation-defined parameters** | 679 controls with values to set, filled in on the control and carried into the reports |
| **Control origination** | System specific, inherited, hybrid or common, on every control |
| **Guidance on every control** | NIST's own control statement |
| **Get ready** | A plan of 8 stages and 26 steps following the RMF, from describing the system to getting authorised. 21 steps tick themselves from your data |
| **Sample library** | 82 assets and 56 risks, covering every family, to add with one click |
| **Registers** | Evidence, risks, assets, policies, tasks, incidents and findings (your plan of action and milestones), all linked to the controls |
| **Reports (PDF, with your logo)** | Executive summary, baseline and tailoring, gap report, readiness plan, risk register, evidence register |
| **Help and Documentation** | 10 pages in the product, including an RMF playbook and where to find evidence in Microsoft 365, AWS and Google |

## Every Offset product also has

HTTPS with your certificate · four roles · every change recorded in an audit trail that auditors can read and download · nightly
backups and restore from the screen · signed one-click updates · email
reminders and a daily digest · Forgot password for administrators.

## How it installs

| | |
|---|---|
| **Windows** | One installer. Nothing else to install |
| **Linux** | A package that installs as a system service. Ubuntu, Debian, RHEL, Amazon Linux, SUSE |
| **Docker** | Pull the image and run it with Compose |
| **Needs** | A 64-bit server, about 300 MB of disk plus your evidence, and one port. It uses under 150 MB of memory at rest |
| **Sized for** | Up to about 50 users |

## Your data stays yours

It runs on your server, inside your network. No cloud, no telemetry, no
licence server. Offset Security has no access to it. Details are in the
security overview and the privacy sheet.
